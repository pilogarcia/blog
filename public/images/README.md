# Imágenes

- `hero-articulos.jpg` — imagen de fondo del hero en la portada del blog (recomendado: 1920x1080 o más, orientación horizontal, se muestra en blanco y negro con superposición oscura).
- `favicon.png` — ícono del sitio.
- `posts/` — portadas de cada artículo. El nombre de archivo lo elegís vos; después lo referenciás en el campo `cover` del front-matter de cada .md, por ejemplo:
  ```
  cover: "/images/posts/mi-imagen.jpg"
  ```
